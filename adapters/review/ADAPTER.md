## 附加审核偏好（可训练层）

本节由 harness adapter 加载，训练流程会改写它；改这里不需要动代码。
它只补充 base prompt 没规定的细节，不覆盖 base 里的 JSON 格式与严重度定义。

### 合并同源问题
- 同一根因在多处出现时合并成一条，在 detail 里列出全部受影响位置，不要按文件重复报。

### 可复现性
- 每条 blocker / major 至少给一个可复现的输入、调用路径或并发时序；写不出具体触发条件就降级为 minor，并在 detail 里说明前提。

### 与侦察官的分歧
- 侦察官归纳的改动意图与 diff 的实际行为冲突时，以 diff 为准，并在 detail 里点名这处分歧。
